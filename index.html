About

Fresnel Calculator

The original calculator was written in JavaScript and developed in 2012. The source was recovered and moved to GitHub in 2020 so the tool can remain accessible as a static web application.

This landing page provides a stable entry point for the calculator and for additional browser-based tools added in the future.
